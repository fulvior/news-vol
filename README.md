# news-vol

Can news explain volatility? A daily pipeline that relates GDELT news coverage
to the VIX, the VSTOXX and other volatility measures, published at
https://fulvior.github.io/news-vol/

- `pipeline/` – data and modelling scripts, configured in `pipeline/config.yml`
- `data/` – volatility and news series, updated daily by GitHub Actions
- `site/` – the static page deployed to GitHub Pages
